# Gallery browser fixture

`tests/website/gallery.test.ts` generates 480 deterministic Project photos in
`.cache/gallery-fixture`, builds this Vite page and exercises the production
Gallery components. It runs as part of `pnpm test:website`.

The two small videos are synthetic 1.5-second FFmpeg `testsrc2` patterns:

```sh
ffmpeg -f lavfi -i 'testsrc2=size=160x120:rate=12' -t 1.5 -an -c:v libx264 -pix_fmt yuv420p -movflags +faststart live.mp4
ffmpeg -i live.mp4 -c copy -f mov -movflags +faststart live.mov
```

`live.mp4` uses an `isom` brand; `live.mov` uses a real QuickTime `qt  ` container.
The Motion Photo fixture is generated by appending the MP4 to a valid local JPEG,
with exact offset/size metadata. No external photos, video downloads or FFmpeg
installation is needed to run the tests.
